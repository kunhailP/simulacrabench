# The exploration cost of learning boundary and population causal effects

Replication materials for the manuscript **"The exploration cost of learning boundary and population causal effects"**
by Kunwoo Park (Department of Political Science and International Relations, Kookmin University;
ORCID [0009-0007-9067-8964](https://orcid.org/0009-0007-9067-8964)).

The paper studies logs generated by a known assignment policy that increasingly favors a preferred
action, and measures the cost of learning by the cumulative operational value forgone through
alternative actions (exploration loss). In one outcome model, the effect at the policy's decision
boundary admits asymptotically valid inference while exploration loss tends to zero, whereas the
population average effect requires divergent worst-case loss for uniformly consistent estimation.

No new participant data were collected. All numerical results are simulations or deterministic
numerical calculations.

## Reproducing

Requirements: Python 3.10+, `numpy`, `pandas`, `matplotlib` (see `requirements.txt`), and a LaTeX
distribution with BibTeX (or [Tectonic](https://tectonic-typesetting.github.io)).

```bash
pip install -r requirements.txt
bash reproduce.sh            # all experiments, figures, generated tables, then the PDF
```

or step by step:

```bash
cd simulation/src/separation
python run.py finite         # information bound in finite contexts (closed form)
python run.py kantorovich    # misspecified-gap bound (closed form)
python run.py costs          # design costs under the sparse-exploration criterion (quadrature)
python run.py audit          # counterexamples delimiting the scope of the results (quadrature)
python run.py phase          # exact risks and exploration loss over temperatures (quadrature)
python run.py designs        # exploration designs, Monte Carlo
python run.py designs --rate --ns 10000 100000 1000000 --reps 200
python run.py boundary       # boundary inference, Monte Carlo
python run.py coverage       # coverage diagnostics, Monte Carlo
python run.py --out ../../results/separation/coverage_n1e6_r5000 coverage --ns 1000000 --reps-list 5000 --seed 20260920
python run.py curve          # fixed-n temperature sweep, Monte Carlo (parallel)
python run.py firstorder     # accuracy of the first-order RMSE of the boundary estimator (parallel)
python run.py rdcompare      # Theorem 1 estimator vs local-linear comparison at 0 on the same logs (parallel)
python run.py rdlimit        # probability limits of both boundary estimators (quadrature)
python plot_figures.py       # Figures 1-4
cd ../../../paper/tex
python make_separation_tables.py
latexmk -pdf main_jci.tex    # or: tectonic main_jci.tex
```

The Monte Carlo runs use fixed seeds; `curve` uses a process pool (`--procs`). Total run time is
roughly 20 minutes on a many-core machine.
