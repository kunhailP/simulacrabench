# 전략: 남들과 반대로 가는 지점

리더보드 상위 40팀은 0.640–0.653에 몰려 있고, UNICEF 0.52 / WB 0.50은 거의 전원이 같다. 같은 방향(조건부 분포 + gate 규칙 + 리더보드 튜닝)으로 경쟁하면 0.00x 차이와 bootstrap 동점 판정에 운을 맡기게 된다. 다음은 다수가 하지 않을 것으로 보이는 선택들이다. 각 항목에는 근거와 검증 방법을 붙인다.

## 1. 리더보드를 쫓지 않는다
- **다수:** 하루 1회 점수를 보고 튜닝한다. 그러나 0.01 반올림 아래의 차이는 보이지 않아서 사실상 DEV 621~1,488명에 과적합하게 된다.
- **우리:** 모든 결정은 `predict()` 안의 CV로 실행 시점에 내린다. 리더보드는 가설 검증에만 쓴다(SUBMISSION_PROTOCOL.md).
- **근거:** Test는 DEV와 다른 응답자이고 한 번뿐이다.

## 2. 최종 단계는 다른 기계로 본다
- **다수:** Dev용 모델을 그대로 낸다.
- **우리:** 최종 단계에서는 DEV 행이 학습에 추가되고(+7~10%), 시간도 3,600s로 4배다. 남는 예산을 감지해서 앙상블 크기·seed·fold 수를 늘리는 **예산 적응형** 구조로 만든다. 한 번뿐인 제출이라 분산 감소 자체가 이득이고, 동점 판정에서도 유리하다.
- **검증:** phase 2 모드에서 같은 코드가 더 좋아지는지 sim 시나리오로 확인한다.

## 3. gate를 규칙이 아니라 데이터로 본다
- **다수:** 공식 LLM 베이스라인처럼 부모가 GIVEN이면 sentinel을 0/1로 확정한다.
- **우리:** gate는 사전정보로만 쓰고, `P(NA_GATED | 부모, wave, 국가)`는 학습 행에서 직접 추정한다. UNHCR 일치도는 0.29–0.98이다. 확신 오답 1셀 = −6.9.
- **추가:** gate 위반 패턴 자체를 예측 신호로 쓴다. 예: 어떤 국가·wave에서 routing이 깨지는가.

## 4. LLM은 "응답자"가 아니라 "구조 사전정보"로만 쓴다
- **다수 (또는 그 반대 극단):** LLM이 응답을 생성하거나, LLM을 완전히 무시한다.
- **우리:** 희소 셀, 특히 UNHCR의 213문항에서 **문항 간 의미 유사도**(질문 임베딩)로 문항끼리 정보를 빌려 오는 데만 쓴다. 다중과제 MLP의 출력층을 문항 임베딩으로 매개화하는 식이다. 사피엔스큐 글(통계 > LLM 응답자)과도 모순되지 않는다.
- **검증:** 임베딩 대신 무작위 벡터를 넣은 대조군과 비교한다.

## 5. 소지역 추정의 시각으로 수축한다 (우리의 전문성)
- 국가×종교×역할 같은 셀을 "소지역"으로 본다. 경험적 베이즈 Dirichlet–multinomial(v2에 들어감)에서 계층 구조 HB로 확장한다. 수축 강도는 셀 크기와 셀 간 분산으로 정한다.
- 보정: 문항별 temperature(v2). 그다음은 셀 크기별 보정이다(작은 셀일수록 과신하는 경향).

## 6. 합성 데이터에 과적합하지 않는다
- 단일 sim2는 위험하다. 생성 가정이 다른 시나리오 묶음(GIVEN 정보량 저·중·고, gate 일치도, 상호작용 강도, 문항 간 상관)으로 **최악의 경우에도 marginal을 이기는지** 확인하고, 평균이 아니라 최소값으로 판정한다.

## 우선순위
1 → 6(시나리오 묶음) → 3 → 2 → 5 → 4 순서로 진행한다. 4는 비용이 커서 앞의 것들이 포화된 뒤에 한다.
