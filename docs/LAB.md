# 실데이터 실험실 (2026-10-09~)

합성 world는 우리가 구조를 심었기 때문에 이길 수 있다(순환성). 그래서 **공개 실제 설문 원자료**를 대회 형식으로 바꿔 실험실로 쓴다. 대회 데이터가 GSS와 닮았다는 뜻은 아니다. 다만 데이터가 **진짜**라는 점이 다르다.

## 데이터

- 평가 `tools/lab.py`: 반복 무작위 분할(15% hidden), 공식 floor·skill 그대로, 셀별 log score를 저장해 쌍대 비교
- 캐시 `tools/oof.py` + `tools/blend.py`: 모델별 OOF·hidden 표를 저장하고, 조합을 몇 초 만에 시험

## 결과 (GSS, rep0. skill은 정확값)
| 모델 | hidden skill |
|---|---:|
| marginal | 0.3951 |
| EB backoff | 0.4728 |
| sint | 0.4768 |
| LightGBM (문항별, 범주 분할) | 0.4784 |
| MLP (최적 epoch) | 0.4788 |
| v7 블렌드 | 0.4798 (3회 평균 0.4810) |
| **TabICLv2** (공개 가중치, 문항별, n_est=4) | **0.4818** |
| TabICL + MLP, 기하평균 결합 | 0.4821 |

1. **계열이 다른 모델들이 0.005 안에 모인다.** 리더보드가 평평한 것과 같은 현상이다.
2. **학습곡선 (v7, 3회 평균):** 25% 0.4742 → 50% 0.4780 → 100% 0.4810. 두 배로 늘릴 때의 이득이 0.0038 → 0.0030으로 n^-0.34 수준으로 느리게 줄어든다. 외삽하면 남은 추정 이득은 약 0.01 skill이다. 승부는 이 0.01 안에서 갈린다.
3. **TabICL이 v7보다 +0.002**로 가장 크게 앞선다. 데이터 효율이 높은 추정량이 이긴다는 가설과 맞는다.
4. **모델-사전 EB(셀 단위 재보정)는 이득이 없다.** EB·TabICL 사전 위에서 α가 상한에 붙는다. 셀 수준의 보정 오차가 없다는 뜻이다. 진단 도구(모형의 유효 표본 크기)로만 남긴다.
5. **선형 블렌드는 이득이 거의 없다.** hidden 정답으로 가중치를 맞춘 상한도 0.4813(보정 전)으로 TabICL 단독과 같다. 기하평균 결합은 +0.0003이다.
6. **OOF와 bag의 불일치:** fold 하나의 OOF보다 5-fold bag 예측이 hidden에서 더 좋다(MLP +0.0023, LightGBM +0.0017, TabICL +0.0009). 블렌드 가중치는 OOF로 맞추므로 분산이 큰 모델의 실제 품질을 과소평가한다. 다만 블렌드 이득이 원래 작아서 영향도 작다.
7. TabICL은 전체 visible을 문맥으로 한 번 fit한 결과(0.4811 raw)가 5-fold bag(0.4812 raw)과 같다. 실전에서는 fit 한 번이면 된다(5배 빠름).

**안전성**
- 공식 score.py: sandbox 세 기관 phase 1 PASS, phase 2 UNICEF PASS. WB phase 2는 0.2423으로 marginal fallback이 작동했다. 실험 4개가 GPU를 같이 쓰던 상황이라 OOM으로 추정한다(단독 재현은 정상).
- 대응: 예외가 나면 GPU 캐시를 비우고 TabICL 없이 v7로 재시도한다. 그것도 실패할 때만 marginal을 낸다.
- **v7 잠재 버그 (v8에서 수정):** sint의 local fdr 추정(`_lfdr`, 포아송 IRLS)이 가끔 `LinAlgError: Singular matrix`로 죽는다. GPU 연산이 비결정적이라 실행마다 재현 여부가 다르다(sandbox WB에서 확인). v7 단독이었다면 해당 기관 전체가 실패한다. v8은 행렬 크기에 비례한 릿지, `lstsq` 대체 풀이, 비정상 값이면 반복 중단, 실패하면 lfdr=1(모두 귀무)로 막는다. 정상 입력에서는 v7과 결과가 같다(20개 입력 검사).
