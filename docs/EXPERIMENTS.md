## 관찰
- sim2에서 MLP 가중치가 0.7–0.9로 지배적이다. sim2의 생성 구조 때문일 수 있어서 실데이터에서도 그런지는 모른다.
- sim2에서는 L2 격자와 MLP epoch가 격자 끝값에서 선택된다. 실데이터에서는 런타임 CV가 알아서 고르므로 격자를 넓게 두는 게 안전하다.

## H1/H2 내부 판정 (METHOD_PROPOSAL.md, 2026-10-08)
- **H1 (단변량 FH ≥ v2): 판정 보류.** 손해는 없으나(최선 설정에서 −0.00005~+0.0002 nats/cell) 이득도 없다.
- **H2 (다변량 FH > 단변량 FH): 내부 기각.** sim2(셀효과 없음), sim3(저랭크 셀효과 있음) 모두에서 이득이 0이고, 깊은 셀에서는 손해다.
- 부수 발견: 고차원 BLUP에서 셀효과 공분산의 상위 고유값 편향이 과적합의 주원인이었다. 셀 라벨 순열 null로 고유값을 빼면 손해가 사라진다(안전성 확보). 이것만으로는 점수 이득이 없다.
- 해석: 교차적합된 다중과제 MLP가 이미 "셀 효과의 수축 추정량" 역할을 한다. 그래서 그 위에 얹는 FH 층에 남는 신호가 없다. 실데이터에서 다를 가능성은 있다(실제 셀 효과 구조는 모름). 다만 사전등록 규칙상 이 방향을 주력에서 내린다.

## 오라클 world와 headroom 분해 (2026-10-08, `tools/world.py`, `headroom.py`, `learning_curve.py`)
오라클 headroom은 **시뮬레이터 진단용**이다. 실데이터에서 더 갈 수 없다는 근거로 쓰지 않는다. 실데이터의 P(y|GIVEN)은 알 수 없고, 리더보드 정체는 다들 같은 방법을 쓴 결과일 수 있다.

| world | UNICEF v2 / 오라클 | WB v2 / 오라클 | v4−v2 |
|---|---|---|---|
| base | 0.4383 / 0.4485 | 0.3885 / **0.4338** | 0 |
| weakx | 0.2909 / 0.2940 | 0.2805 / 0.2920 | 0 |
| strongx | 0.5398 / 0.5495 | 0.5373 / **0.6145** | 0 |
| cells | 0.4318 / 0.4438 | 0.4290 / **0.4845** | 0 |
| cleangate | 0.5497 / 0.5558 | 0.4360 / **0.4811** | 0 |

- v4(PREDICT 부모 gate 분해): UNICEF·WB에서 효과 없음. 해당 문항이 거의 없다(WB 1560/39520셀). UNHCR에서 따로 판정한다.
- WB base 분해: 초과손실 0.096 nats/셀이고 76문항에 고르게 퍼져 있다(최대 문항 2.4%). hidden 행의 98%는 GIVEN 패턴(9열)이 visible에 **한 번도 없다**. 퍼진(고엔트로피) 오라클 셀이 손실의 59%다.
- WB base 학습곡선 (같은 DEV, TRAIN 재추출): n=5195 → 0.096, 20k → 0.069, 60k → 0.053. 데이터를 11배로 늘려도 절반밖에 줄지 않는다. 따라서 **모델 형태(근사) 오차가 크다.** 표본 크기만의 문제가 아니다.
- 해석: 참 P(y|x) = ∫ softmax(η_j(x) + λ_j z) dF(z|x)로, 잠재특성에 대한 혼합이다. 문항별로 직접 맞추는 모형(lin/MLP)은 이 혼합 형태를 비효율적으로 근사한다. 그런데 λ_j는 visible 행의 **문항 간 공변동**에서 정밀하게 식별된다. → 다음 가설 H3: 응답자 수준 잠재요인 모형(조건부 IRT, x에 의존하는 z 분포)으로 학습하고 z를 적분해서 주변분포를 내면 headroom을 줄인다. (H2의 셀 수준 다변량 FH와는 다르다. 이쪽은 응답자 수준 공변동을 쓴다.)
