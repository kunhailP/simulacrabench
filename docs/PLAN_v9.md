# v9 실험 계획 (2026-10-10 사전등록)

목표: 0.67 (예: UNICEF 0.54 / WB 0.52 / UNHCR 0.95). 현재 v8은 0.52 / 0.49 / 0.93(표시 평균 0.6467)이다. 10-10 리더보드 1위는 여전히 0.52 / 0.50 / 0.94다.

## 0. 목표를 손실로 환산 (공식 스키마의 U로 계산, 검증함)
| 기관 | 목표 | 필요한 감소 (nat/셀) | 남은 손실 대비 |
|---|---|---:|---:|
| UNHCR | 0.93 → 0.95 | 0.0252 | 28.6% |
| UNICEF | 0.52 → 0.54 | 0.0312 | 4.2% |
| WB | 0.49 → 0.52 | 0.0605 | 5.9% |

- UNHCR `s3_11`의 자식 73문항에서 평균 0.074 nat를 줄이면 +0.02다.
- UNICEF 4문항에서 평균 0.094 nat를 줄여도 +0.02다.
- WB 임금 두 문항만으로 +0.03을 내려면 문항당 2.30 nat가 필요하다. 불가능하므로 WB는 문항 가족 전체를 공략해야 한다.
- 0.67은 지금까지 실험실에서 본 어떤 이득(TabICL +0.0025)보다 한 자릿수 크다. 구조적인 이득이 없으면 도달할 수 없다.

## 1. 외부 검토(붙여준 분석) 확인 결과
| 주장 | 판정 | 근거 |
|---|---|---|
| `m_linear` 벌점이 문항 수 J에 비례해 실질적으로 강해짐 | **확인** | 손실은 셀 평균(`_nll`), 벌점은 `l2*(W**2).sum()`(모든 문항의 합). `m_sint`도 같다. UNHCR은 UNICEF보다 약 18배 강하다. |
| 로그 결합(`_pool_weights`)이 floor를 반영하지 않고 가중치 제약도 없음 | **확인** | `sub/v8/main.py` |
| TabICL 분기 분해가 남는 시간에만 실행됨 | **확인** | 세 번째 기관 UNHCR에서 실제로 잘렸는지는 `tools/budget_probe.py`로 측정한다 |
| OOF 메타 적합을 여러 단계 쌓음 → 내부 검증이 낙관적 | 확인, 단 영향은 제한적 | `tools/lab.py`는 `predict()` 전체를 숨긴 15%에서 채점한다. 그래서 실험실의 최종 숫자는 정직하다. 낙관적인 것은 내부 선택뿐이다. |
| 실험실 gate를 전체 행으로 추론 (평가 행 정보 포함) | 확인, 우선순위 낮음 | 대회 스키마도 주최 측이 전체 파일로 만들었다(UNHCR gate 하나는 skip rate로 추론). 실험실의 이 성질은 대회와 같다. |
| GSS 결과를 대회로 넓게 일반화함, 반복 SE ±0.0001을 전이 불확실성으로 읽으면 안 됨 | **동의** | → §2 평가 묶음(실험실 역할 고정, 최악 실험실 기준) |
| 학습곡선 외삽 "남은 몫 0.01"은 GSS 한정 | 동의 | 상한으로 쓰지 않는다 |

## 2. 평가 체계 (`tools/suite.py`)
- 실험실 역할은 미리 고정한다. **develop**(gss, gss_hcr), **select**(gss_wb, gss_branch, 그리고 새 공개 설문), **final**(새 공개 설문 1~2개, 마지막에 한 번만 본다).
- 채택 규칙은 select 실험실 **전부에서** 쌍대 차이 > 0인 것이다. 평균이 아니라 최악의 실험실로 판정한다.
- 출력은 문항 가족별로 분해한다(gate 부모 / 이탈 / 일반). 개선이 의도한 구조에서 나왔는지 확인하기 위해서다.
- 구조 실험실(`tools/proxy_gss_struct.py`)은 GSS 실응답에 스키마 문서의 기제만 입힌 것이다.
  - **gss_wb:** 실제 협조도·이해도가 이탈을 일으킨다.
  - **gss_branch:** 실제 3수준 문항을 숨겨진 부모로 쓴다. 일치도는 중앙값 0.82, 1차 조사 행은 "0"으로 기록한다.
  - 기제를 우리가 심었으므로 순환성 위험이 있다. 그래서 select에는 반드시 구조를 심지 않은 실제 설문도 포함한다.
